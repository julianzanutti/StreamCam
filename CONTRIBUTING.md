# Contribuir

El código original de StreamCam se distribuye bajo GPL-3.0-or-later. Conservá las licencias y los avisos de los componentes de terceros. No agregues SDKs, archivos generados, credenciales ni datos de dispositivos al historial.

Para cambios de captura o transporte, verificá selección de lente y formato, reconexión, pérdida de cable/red, detener y volver a iniciar, y pantalla bloqueada. Las pruebas sintéticas complementan la prueba física; no deben presentarse como equivalentes.

Antes de preparar una release, ejecutá compilaciones Android y Windows, lint Android y las pruebas de autenticación, decodificación y salida OBS que correspondan. Documentá qué teléfonos y versiones de Windows/OBS se verificaron, sin números de serie ni datos personales.
